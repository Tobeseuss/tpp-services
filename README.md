# TPP Services | سرویس‌های TPP

پلاگین وردپرس مدیریت اطلاعات سرویس‌های اینترنت و تلفن — با ثبت تکی و گروهی (اکسل)، تاریخچه کامل تغییرات، کار آفلاین (PWA) و همگام‌سازی خودکار.

**نسخه فعلی: `1.20.0`** | پیش‌نیازها: WordPress 5.8+ و PHP 7.4+

---

## ✨ امکانات

- **سرویس‌ها:** ثبت تکی و گروهی (اکسل) با تشخیص هوشمند آدرس‌های مشابه، چند سرویس برای هر آدرس، جستجوی زنده اجاکسی، فیلدهای داینامیک قابل افزودن/حذف با دسترسی سطح فیلد
- **پیشرفت دایری:** ۱۶ مرحله با منطق آبشاری + انتخاب چند خرابی برای هر سرویس + تغییر گروهی/تکی
- **کار آفلاین:** اپ PWA فارسی (RTL) با IndexedDB، صف همگام‌سازی و اجرای خوش‌بینانه عملیات + Service Worker با به‌روزرسانی خودکار
- **تاریخچه و گزارش کار:** تاریخچه آبشاری تغییرات با بازگردانی، گزارش کار روزانه/بازه‌ای هر کاربر با تقویم شمسی، گزارش فعالیت جامع
- **خروجی‌ها:** اکسل (نویسنده/خواننده XLSX بومی بدون وابستگی)، PDF دو روشه (TCPDF باندل‌شده + چاپ مرورگر)، بکاپ JSON و SQL/ZIP با بازیابی کامل + پشتیبان خودکار قبل از ایمپورت
- **پیامک:** پنل SMS.ir با قالب‌های پیامک و کپی مشخصات (OMC)
- **دسترسی‌ها:** نقش‌های کاربری داینامیک + پنهان‌سازی خودکار منوها/دکمه‌های بدون دسترسی
- **بازبینی (۱.۲۰.۰):** دسته پیش‌فرض ارجاع «ثبت جهت بازبینی و ویرایش یا تأیید مدیریت» + سجل اقدامات نصاب‌ها با نگه‌داری/بازگردانی یک‌کلیکی
- **مرکز API:** ۲۵+ مسیر REST (`tpp/v1`) با مستندات کامل برای اتصال افزونه‌های دیگر + شورت‌کد `[tpp_services]`

## 📦 نصب

1. آخرین نسخه را از [Releases](https://github.com/Tobeseuss/tpp-services/releases) یا کل این ریپو دانلود کنید.
2. پوشه `tpp-services` را در `wp-content/plugins/` قرار دهید (یا zip را از **افزونه‌ها ← افزودن ← بارگذاری** نصب کنید).
3. افزونه **TPP Services | سرویس‌های TPP** را فعال کنید.
4. اپ تحت آدرس `/wp-content/plugins/tpp-services/pwa/` در دسترس است؛ در پیشخوان هم لانچر دارد. برای سایت عمومی از شورت‌کد `[tpp_services]` استفاده کنید.

> ارتقا: «جایگزینی نسخه فعلی» از صفحه افزونه‌ها؛ مهاجرت دیتابیس و seedهای نسخه جدید به‌صورت خودکار انجام می‌شود. یک بار اپ را رفرش کنید تا Service Worker جدید فعال شود.

## 🗂 ساختار

```
tpp-services/
├── tpp-services.php        # بوت‌استرپ افزونه + محافظ کپی تکراری
├── uninstall.php           # پاک‌سازی هنگام حذف

└── pwa/                    # اپ تحت‌شبکه (PWA): SPA فارسی RTL + Service Worker + IndexedDB
```
