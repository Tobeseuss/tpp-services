# TPP Services

پلاگین وردپرس **سرویس‌های TPP** — چارچوب پایه برای مدیریت و ارائه سرویس‌های برند TPP در وردپرس.

> 💡 **نکته:** این فایل قالب آماده است؛ جاهای مشخص‌شده با `<!-- -->` را با اطلاعات واقعی برند و سرویس‌های خودتان تکمیل کنید.

---

## معرفی

پلاگین `tpp-services` با هدف متمرکزکردن سرویس‌های برند TPP در یک هسته سبک و قابل توسعه ساخته شده است. این پلاگین از یک ساختار تک‌فایلی مینیمال (Bootstrap) شروع می‌شود که آماده گسترش به ماژول‌های جداگانه برای هر سرویس است. نسخه فعلی شامل هسته راه‌اندازی، بارگذاری ترجمه‌ها و یک endpoint سلامت (Health Check) در REST API است که پایه فنی مناسبی برای اضافه‌شدن سرویس‌های بعدی فراهم می‌کند.

این ریپازیتوری کد اختصاصی برند TPP است و انتشار، کپی یا تغییر آن بدون اجازه مالک مجاز نیست. برای مشاهده قوانین کامل به بخش [مجوز](#مجوز) مراجعه کنید.

## ویژگی‌ها

- **هسته Singleton سبک:** راه‌اندازی پلاگین با الگوی استاندارد وردپرس و بدون سربار اضافه.
- **REST API آماده:** endpoint سلامت در مسیر `/wp-json/tpp-services/v1/health` برای مانیتورینگ وضعیت سرویس.
- **چندزبانه:** بارگذاری خودکار فایل‌های ترجمه با text domain استاندارد `tpp-services`.
- **هوک‌های چرخه حیات:** مدیریت تمیز فعال‌سازی/غیرفعال‌سازی شامل ذخیره نسخه و بازسازی rewrite rules.

## نصب

1. آخرین نسخه را از بخش [Releases](https://github.com/Tobeseuss/tpp-services/releases) دانلود کنید (یا ریپو را clone کنید).
2. پوشه `tpp-services` را در مسیر `wp-content/plugins/` سایت وردپرسی خود قرار دهید.
3. از پیشخوان وردپرس به **افزونه‌ها** بروید و پلاگین **TPP Services** را فعال کنید.
4. برای اطمینان از صحت نصب، آدرس `/wp-json/tpp-services/v1/health` را در مرورگر باز کنید؛ پاسخ JSON با `status: ok` باید نمایش داده شود.

نصب با Git:

```bash
cd wp-content/plugins
git clone https://github.com/Tobeseuss/tpp-services.git
```

## توسعه

کد اصلی در `tpp-services.php` قرار دارد و با الگوی Singleton کار می‌کند. برای افزودن سرویس جدید:

1. تابع ثبت مسیر جدید را داخل `register_rest_routes()` اضافه کنید یا یک کلاس جداگانه بسازید.
2. هنگام ارتقای نسخه، ثابت `TPP_SERVICES_VERSION` را به‌روزرسانی کنید.
3. تغییرات را با پیام کامیت معنادار (ترجیحاً مطابق [Conventional Commits](https://www.conventionalcommits.org/)) ارسال کنید.
